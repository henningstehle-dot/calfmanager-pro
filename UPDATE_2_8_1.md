# CalfManager Pro 2.8.1 – Archivkorrektur

- Archivierungsaktion kontrolliert die tatsächlich zurückgegebenen Datensätze und den neuen Status.
- Bei keiner aktualisierten Zeile wird eine Fehlermeldung angezeigt statt eines falschen Erfolgs.
- Archivieren / Reaktivieren am Ende der Kälberdetailansicht.
- Direkter Archiv-Button in der Kälberübersicht.
- Keine neue SQL-Migration notwendig.

## Installation
Projektdateien in GitHub ersetzen und GitHub Actions Build prüfen. Keine SQL-Änderung ausführen.

## Hinweis
Lokaler Build konnte wegen nicht verfügbarer npm-Abhängigkeiten nicht ausgeführt werden.
Falls die Aktion nun einen Fehler zeigt, bitte Fehlermeldung übermitteln.
